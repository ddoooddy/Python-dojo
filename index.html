Python Dojo

Práctica deliberada, método socrático

Acá se aprende resolviendo, sin adivinar nada: cada tema arranca con una sección Concepto que explica todo desde cero, sigue con un tutorial interactivo donde ejecutás código y ves qué pasa, y recién entonces vienen los ejercicios. La solución aparece después de que intentás, con su porqué.

El código Python corre de verdad en tu navegador y el progreso se guarda solo. Para experimentar libre tenés el Playground (abajo a la izquierda); para fijar lo aprendido, el botón Repaso de arriba. Punto de partida recomendado: Básico → Variables y tipos.

Para que el volumen no abrume, los ejercicios se desbloquean de a 5 cada 24 horas, en orden: cada día te espera un lote nuevo. Lo ya resuelto queda siempre disponible.
